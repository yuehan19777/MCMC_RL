# 实验产物索引

优先阅读 `final_comparison/REPORT.md` 和项目 `docs/FINDINGS.md`。

| 目录 | 用途 | 是否用于最终主结论 |
|---|---|---|
| `pilot_v1/` | 原始预算的第一轮探索，保留原始源码快照和全部数据 | 仅开发过程对照 |
| `pilot_v2/` | 增大批次、降低学习率、增大ridge后的第二轮 | 复用其中RWM/AM/MALA的27组经典结果 |
| `refined_learned/` | 最终成对链分组后重跑ESJD/Poisson，共18组 | 是 |
| `classical_scale_check/` | 相同最终训练转移预算下的8候选ESJD尺度网格，共9组 | 是 |
| `final_comparison/` | 引用上述最终54组结果的总表、报告与八张图 | 是，主入口 |
| `validation/` | 检查点恢复、数学测试、短流程smoke归档和产物完整性审核记录 | 正确性证据；smoke不作效果结论 |

最初两个探索轮次按奇偶链分配Critic/Actor数据；双峰初值也按奇偶分配左右模式。
虽然训练中会发生跨峰，该分组让早期两个训练子集的模式覆盖不均。
最终代码改成相邻链成对分组，并完整重跑ESJD和Poisson。经典方法从未使用该分组，故可直接复用。
没有基于最终结果挑选某个种子或某个任务的最佳版本。

每组训练内保持共同pilot；每个方法独立冻结后评估，最终比较使用同一套最终超参数和相同评估协议。
预实验未留出确认性测试任务；任何优势都属于探索性结果。

`source_snapshot/` 保存各轮实际执行的Python模块，`manifest.json` 记录源码摘要。
最终汇总文件中的 `artifact` 是指向原始目录的相对路径，因此请整体移动项目，避免只搬走汇总目录。
模型检查点可以用项目 `scripts/sample_checkpoint.py` 恢复。
