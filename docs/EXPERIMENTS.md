# 实验协议与指标解释

## 预算和公平性

每个任务、种子共用同一份 16 链×256 步 pilot，估计初始中心、协方差和 RWM 尺度。
训练初值是分散的非平稳状态；双峰初值分布在两侧，训练并非从未发现任何模式的极端情况。
第一轮每个方法使用16链×96轮×16步适配；最终配置增加为16链×128轮×32步，即65,536次转移。
最终加pilot后每种方法有69,632次训练转移。学习方法另有32,768个Actor proposal。

所有方法适配结束后均冻结；评估 8 链×5000=40,000 次转移。
最终三任务×六方法×三种子共54组固定kernel评估。额外的第六种方法是固定pilot协方差的预条件RWM，
在8个尺度上按训练期ESJD选尺度，每个候选均分适配转移预算。
双峰还有6×3组、每组8链×2500步的冷启动测试，仅用于模式切换，未计入主ESS/秒。

各方法训练转移数相同，**总浮点预算和目标调用数并不相同**：

- RWM、AM 使用密度；MALA 额外使用解析梯度。
- 本实现不缓存 π(x)，每个 MH 转移计算两次目标密度。
- MALA 每个转移计算三次梯度：sample mean(x)、forward density mean(x)、reverse density mean(y)。
- 学习方法的额外 Actor proposals 在 score loss 中计算两次目标密度。
- GPU 未使用，单 CPU 线程、float64。首次优化器基础设施导入在计时外预热。

ESS/密度调用只能比较密度预算，不能消除 MALA 梯度或神经网络运算成本。
端到端 ESS/秒包含每个方法自己的 pilot+adaptation+evaluation；共享 pilot 的耗时按每个单独运行的方法各计一次。
每个机器运行速度不同，秒数只是当前实现和机器上的数据，不能直接推断最佳优化实现的排名。
绘图、压缩和文件写入不计入 kernel 性能计时。

## 两种独立评估协议

主实验为平稳态效率实验：用目标分布的独立解析采样器初始化评估链，随后完全使用冻结 MH kernel。
这个评估工具在三种合成任务上都可用，有助于避免把初始偏差混同于渐近方差。
训练、共同 pilot、方法调参均不能访问该采样器或解析矩。
各方法使用相同评估初值与同一个基准随机数种子，之后因 kernel 不同轨迹自然不同。

压力实验仅用于双峰：所有链从左峰附近出发，记录第一次到达右峰的时间、未切换比例以及右峰累计占比。
未切换链使用右删失标记，而不是填入一个真实的命中时间。
这个压力实验测试适配后 kernel 的跨峰能力；由于训练已暴露两峰，它不能证明从未知单峰训练也能发现另一峰。

## 统计函数

训练：x0、x1，按共同 pilot 标准化，目标为两者 ASV 的平均。
评估：原始尺度的 x0、x1、x0²、1{x0>0}，使用已知解析均值和边际方差。
训练标准化矩估计有噪声，因此评估时两个训练统计函数按真实方差归一化后的平均仅是便于解释的汇总，
与有限 pilot 下实际目标权重不完全相同。

## 指标

| 指标 | 计算和解读 |
|---|---|
| Spectral ASV | FFT 自协方差、链间方差修正、Geyer initial positive/monotone 序列；主指标 |
| Normalized ASV | ASV / Varπ(f)，平稳链中即 IACT，越低越好；反相关时可小于1 |
| Batch ASV | 非重叠 batch means，batch size=floor(sqrt(N))；另存 N/10 的较长 batch 作敏感性对照 |
| Replicate ASV | 每个已训练 kernel 下 N·Var(8条独立链均值)，独立检验有限时间方差，只有7个自由度 |
| ESS | MN·Var估计/ASV估计，报告总 ESS、ESS/步、ESS/秒；反相关时不强制截为 MN |
| RMSE | 8条链各自估计均值的误差平方平均开方；另报标准化值及均值偏差 |
| R-hat | rank-normalized、folded、split 后取最大；用于警示未混合，不证明收敛 |
| Acceptance | 实际接受比例；诊断量，不是 Poisson 的优化目标 |
| Mode crossing | x0 符号切换；只有双峰任务才解释为跨模式切换 |

ESS 使用原统计函数，不是 Stan bulk/tail ESS。R-hat 和 ASV 都可能在很短链或极慢链上失真。
特别是双峰各链不跨峰时，单链 batch means 可能几乎看不出模式占比误差；
跨链谱估计、链均值方差、R-hat 和冷启动应共同检查。

跨训练种子用均值±SE展示，但只有3个种子，不能声称正式显著性。
不同训练种子对应不同已训练 kernel，先各自在固定 kernel 下计算 replicate ASV，再汇总；
不会把不同 kernel 的链当成同一个 kernel 的独立重复。

实现依据：[Stan Posterior Analysis](https://mc-stan.org/docs/reference-manual/analysis.html)。
